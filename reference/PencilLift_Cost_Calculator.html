Use the estimate correctly

Start with the typical preset, then replace token counts, retries and usage with real pilot data. The prototype must log provider usage and cost by family and feature without logging children's homework or answer keys.

All-Astra mode changes every modeled stage to GPT-6 Astra while retaining the same request and recheck counts. It is an approximate routing comparison. Review subjects and question counts are fixed in this tool; if changing them in the app, adjust bundle tokens and verification budgets too.

Native subscriptions assume a 15% store rate. Apple eligibility, storefronts and Google programs can change the rate. Optional web Stripe billing is a separate channel and is not included or added on top of a store transaction.
