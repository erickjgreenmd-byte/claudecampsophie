# PencilLift verified project lessons (spec E5.5, AC_ECC_11)

Accepted lessons only; each cites evidence. Project-scoped; never overrides requirements or permissions.

| Lesson ID | Trigger / scope | Proven root cause | Correction / prevention | Evidence | Revalidate when | Status | Revision |
|---|---|---|---|---|---|---|---|
| L-001 | Creating Postgres roles in migrations/test setup | Roles are cluster-wide; `if not exists` check-then-create races between concurrent sessions | Wrap `create role` in a DO block catching `duplicate_object` and `unique_violation` | BUG-001 | Postgres major upgrade | accepted | 0e3c56e |
| L-002 | Any new function in `app`/`public` | Postgres grants EXECUTE to PUBLIC by default, and `ALTER DEFAULT PRIVILEGES IN SCHEMA … REVOKE` cannot remove a global default (per-schema defaults only add). The first version of this lesson wrongly trusted the schema-level revoke | Global `ALTER DEFAULT PRIVILEGES REVOKE EXECUTE ON FUNCTIONS FROM PUBLIC` in 0001 + explicit revoke/grant per SECURITY DEFINER function; `schema_invariants.test.ts` fails if anon can execute any | BUG-002 | New schema, or migrations run by a different role | accepted (corrected) | 0e3c56e |
| L-003 | Any child (`pl_child`) query | Child access uses column-level grants; `select *` is denied (fail closed) rather than filtering columns | API child queries and DTO builders must name the allowlisted columns explicitly; tests assert both the allowlist and that `*`/forbidden columns are denied | `supabase/tests/learning.test.ts` (2 initial failures from `select *` in tests) | Child-readable columns change | accepted | 4393cc3 |
| L-004 | Any pre-commit check in shell | Piping a check into `grep`/`tail` discards its exit status, and a commit on its own line runs regardless of an earlier failed check (BUG-003, BUG-004, BUG-024) | Gate commits with `scripts/verify.sh`; the versioned `scripts/git-hooks/pre-commit` hook (enabled via `core.hooksPath`) blocks lint/format/secret failures on staged files independent of the command line | BUG-003, BUG-004, BUG-024 | Shell/CI changes | accepted (strengthened) | e771721 |
| L-005 | Upserts with `ON CONFLICT … DO UPDATE … WHERE` guards | A guard that fails turns the write into a silent no-op; if later logic trusts in-memory state, data is silently wrong (BUG-006) | Add `RETURNING` and assert the row count; keys for provider objects must be globally unique (include the subscriber identity) | BUG-006 | Any new provider/external-id upsert | accepted | 408bf6d |
| L-006 | Writing JSON to Postgres with postgres.js | A JS string bound to a `jsonb`-typed parameter is JSON-encoded again, producing a string scalar (BUG-008) | Bind `${JSON.stringify(x)}::text::jsonb` (or `sql.json(x)`); every jsonb column carries a `jsonb_typeof in ('object','array')` check and a schema invariant enforces it for new columns | BUG-008 | postgres.js major upgrade, new driver | accepted | f820986 |
| L-007 | Any client code that needs a child or parent token | Rotating refresh tokens tolerate exactly one refresher per device; a second, independent refresher eventually replays a token and the server revokes the session (BUG-012) | Obtain tokens only from `apps/mobile/src/lib/app-session.ts` registrations / `family/runtime.ts childSession`; never create another refresher | BUG-012 | New app shell or auth library | accepted | fe51dc2 |
| L-008 | Committing part of a working tree while other agents (or unfinished work) share it | Tests, typecheck and lint on the working tree prove the combined tree, not the commit: 39ca165 imported `@pencillift/domain/scheduling`, which was still untracked, and passed every check (BUG-034) | The pre-commit hook typechecks the index itself (`scripts/check-staged-tree.sh`: `checkout-index` into a temp dir, workspace links re-pointed at the index copy). Mutation-checked by un-staging the imported module | BUG-034 | Any partial commit; any new workspace package | accepted | de72c0c |
| L-009 | Any destructive or protective state change that work in flight can race (deletion, consent withdrawal, purge) | Deletion flipped only queued jobs, and checks ran once at job start, so running work kept writing (BUG-053, BUG-056) | Put the tombstone on the rows workers compare-and-set, re-check inside each write under a row lock, and take the parent lock in BEFORE INSERT triggers for late writes | BUG-053, BUG-056 | New job kind or new child-scoped table | accepted | 71122c8 |
| L-010 | Budgets, counters and lockouts shared across requests | Peek-then-hit and read-modify-write in application memory let concurrent requests pass together (PIN lockout, pairing budget, spend cap) | Reserve atomically before the work (SQL upsert / row lock), give back on success; never compute an absolute value in the app; a shared budget that runs out pauses only the sources that spent it | BUG-057, BUG-060 | Any new limit or cap | accepted | 71122c8 |
| L-011 | Removal of stored objects | A removal is not final while a signed upload URL can still write the object; soft-delete flags are not proof of removal | Stamp 'confirmed removed' only after storage confirms; record when uploads closed; make the second pass a DB invariant | BUG-054 | New storage-backed table or signed-URL flow | accepted | 71122c8 |
| L-012 | Filtering untrusted content (metadata, answers in hints, links) | Deny-lists and single-form parsers miss new carriers and alternate spellings (BUG-013, BUG-055, BUG-059, BUG-030) | Allow-lists; parse every protectable form and fail closed when a value has none or several candidates; protect the value that actually decided the outcome | BUG-055, BUG-059 | New file type, new answer kind, new text surface | accepted | 71122c8 |
| L-013 | Fixes that depend on wiring someone else owns (scheduler, shared verifier, navigation) | Housekeeping with no caller, a session check only in one middleware, screens with no link: each 'fix' was inert (BUG-033a, BUG-060) | Put the check on the shared dependency every caller uses, let write paths bound their own growth, and add an integration test through the real entry point (tick, app, navigation graph) | BUG-060, BUG-033a | Every fix that adds a function others must call | accepted | 71122c8 |
| L-014 | Any runtime wiring (clients, adapters, handlers) the tests do not construct themselves | Tests built their own Postgres client with default options, so a production-only option (`fetch_types: false`) broke 30+ queries without a single failing test (BUG-063) | Build production dependencies through one factory the tests also use; add a guard test that forbids a second construction path | BUG-063 | New provider client, new runtime option | accepted | 9eb491f |
| L-015 | Any SECURITY DEFINER function granted to `authenticated` (reports, RPCs the API calls as the user) | Every parameter is attacker-chosen, including ones only the API is meant to pass: a school viewer could call the counts report directly with two zones and difference the results, which per-call suppression cannot see (BUG-074) | Pin API-only parameters inside the database (a transaction setting only the API can state, or a stored value) and refuse non-owner calls that differ; test the direct call, not only the API route | BUG-074 | New report or RPC granted to authenticated | accepted | e3b666a |
| L-016 | Selecting a provider when its credential is missing | A mock returns empty or successful state, and empty provider state is destructive: a staging webhook and the stale sweep revoked paid plans from the mock's empty answer (BUG-079) | A missing credential selects an unavailable provider that refuses every call; mocks only in development/test; test the Worker's own selection | BUG-079, BUG-067 | New provider, new environment | accepted | 84fc4d7, 35c1c16 |
| L-017 | Detecting a secret inside an encoding (base64, JWT, minified or compressed output) | Pattern-matching the encoded form misses other alignments and wrappers; scanning sources misses what the build embeds (BUG-081) | Decode before matching (JWT payload roles); anchor on start-of-value, not a word boundary; scan the built artifacts with release-shaped public variables and keep a negative control that must find a planted key | BUG-081 | New build target or encoding | accepted | 35c1c16 |
| L-018 | Any rule-based screen of child language (safety, answers) | Rules written from the builder's own phrasings missed contractions, canonical short forms and first-person statements the context exemptions swallowed (BUG-084 pass 1: 71 adversarial cases failed) | Expand contractions before rules that expect an auxiliary; never let a context exemption be the only rule that can match a first-person statement; keep an adversarial corpus of canonical forms and obfuscations plus an everyday-text false-positive corpus, both run on every change | BUG-084 | New rule, new language, new normalization | accepted | 4b50914 |
